FAQ

Do I need the password?

Yes, you must know the correct password to unlock the PDF. This tool cannot crack or bypass passwords.

What types of protection can be removed?

We can remove user passwords (open password) and owner passwords (permissions). Some encryption types may not be supported in the browser.

Is it secure?

100% secure. Your PDF and password never leave your browser. All processing is done locally using JavaScript.

Can it unlock PDFs without a password?

Some PDFs have owner-only restrictions (no print, no copy) without a user password. These can often be unlocked directly without entering a password.
