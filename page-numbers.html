FAQ

Can I skip the first page?

Yes! Set "Start From Page" to 2 or select "Skip First Page" to skip numbering on cover/title pages.

Can I use Roman numerals?

Yes! Select the "i, ii, iii" format to use Roman numeral page numbers.

Can I change the starting number?

Yes! Set "Start Number" to any value. Useful if your document starts at page 5, for example.

Is it secure?

100% secure. Everything runs in your browser. No files uploaded.
