FAQ

What HTML is supported?

All standard HTML including headings, paragraphs, tables, lists, images (base64/data URLs), and inline CSS styles.

Can I use CSS styling?

Yes! Inline CSS styles and style tags are fully supported. External stylesheets may not load due to browser security.

Is it secure?

100% secure. Everything runs in your browser. No data sent to any server.
