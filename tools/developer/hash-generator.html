FAQ

What is a hash?

A hash is a fixed-size string produced from any input data. Same input always produces same hash. Different inputs produce different hashes (ideally). Used for data integrity verification.

Which hash should I use?

SHA-256 is recommended for most purposes. MD5/SHA-1 are deprecated for security. CRC32 is only for quick checksums, not security.

Can hashes be reversed?

No. Hashes are one-way functions. You cannot recover the original data from a hash. That's what makes them useful for password storage and data integrity.

Is this secure?

Yes! SHA hashes use the browser's built-in Web Crypto API. MD5 and CRC32 use pure JavaScript. All processing is 100% local - no data sent to servers.
