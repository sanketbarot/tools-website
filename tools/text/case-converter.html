FAQ

What is Title Case?

Title Case capitalizes the first letter of each word. Example: "hello world" → "Hello World".

What is camelCase?

camelCase joins words with no spaces, first word lowercase, rest capitalized. Used in JavaScript. Example: "hello world" → "helloWorld".

What is snake_case?

snake_case separates words with underscores, all lowercase. Used in Python/databases. Example: "hello world" → "hello_world".

What is kebab-case?

kebab-case separates words with hyphens, all lowercase. Used in URLs/CSS. Example: "hello world" → "hello-world".
