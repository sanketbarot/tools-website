FAQ

1

What color formats are supported?

HEX (#FF5733), RGB (rgb(255,87,51)), HSL (hsl(14,100%,60%)), and CSS named colors are supported.

2

What are shades and tints?

Shades are darker versions (mixed with black). Tints are lighter versions (mixed with white). Both are useful for creating design systems.

3

How do I copy a color?

Click on any color value (HEX, RGB, HSL) to copy it to clipboard. Click on palette swatches to set them as active color.
