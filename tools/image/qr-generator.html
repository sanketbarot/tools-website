FAQ

What can I encode in a QR code?

URLs, plain text, email addresses, phone numbers, SMS, WiFi credentials, vCards (contacts), UPI payment links, WhatsApp links, map locations and more.

What is error correction level?

Error correction allows QR codes to be readable even if partially damaged. Low=7%, Medium=15%, Quartile=25%, High=30% of data can be restored.

Can I customize colors?

Yes! Pick any QR color and background color. Make sure there's enough contrast for scanners to read it. Use color presets for tested combinations.

What size should I use?

256×256 is good for web use. Use 512×512 for print. Minimum recommended is 128×128 for reliable scanning.
